# Engineering Notes Blog Website

A production-ready personal blog website for a Software Engineer and AI/ML Engineer. Built as a dependency-free static web app with Markdown rendering, local CMS workflows, SEO assets, RSS, sitemap, dark mode, search, filters, related articles, bookmarks, and social sharing.

## Scripts

- `npm run dev` — start a local static development server.
- `npm run build` — copy the production static site to `dist/`.
- `npm run lint` — run JavaScript syntax checks.

## Content management

Open `#/cms` in the browser to create, edit, delete, draft, schedule, categorize, tag, and feature Markdown articles. Content persists in local storage for this static implementation.
